# Высшая лига - ПМИ

Подготовка к олимпиаде «Высшая лига» (НИУ ВШЭ) по направлению «Прикладная математика и информатика».
Сейчас готов отборочный этап: 14 тем, по каждой теория, задачи прошлых лет и тренировочные задачи с подробными решениями.

Начать удобнее всего с заметки [О Высшей Лиге](О%20Высшей%20Лиге.md) → [Отборочный этап](1%20Отборочный%20этап/Отборочный%20этап.md).

## Что внутри

```
О Высшей Лиге.md                 главная заметка
1 Отборочный этап/
    Отборочный этап.md           список тем и карта «год → задание → тема»
    1 Производные/
        Производные - Теория.md
        Производные - Задачи.md
        Производные - Решения.md
    ...                          ещё 13 тем в том же формате
    Варианты по годам/           PDF с заданиями 2021-2025
2 Заключительный этап/           пока пусто
```

Темы 1-10 пронумерованы по варианту 2025 года (номер темы = номер задания), темы 11-14 встречались в прошлые годы.

В задачах сначала идут задания олимпиады (с годом и номером), потом тренировочные. В ключах 2025 года к №3, 6, 7, 9 ответы не совпадают с условиями, в решениях это разобрано отдельно.

## Как открыть

1. Установи [Obsidian](https://obsidian.md) и [Git](https://git-scm.com/downloads).
2. Склонируй репозиторий:
   ```
   git clone https://github.com/djentelmanick/vysshaya-liga.git
   ```
3. В Obsidian: «Open folder as vault» → выбери папку `vysshaya-liga`.

Формулы (LaTeX), ссылки между заметками и граф (Ctrl+G) работают сразу, ничего настраивать не нужно.

## Как синхронизироваться

Чтобы получать обновления и отправлять свои правки прямо из Obsidian:

1. Settings → Community plugins → Browse → установи и включи **Git** (автор Vinzent03).
2. Дополнительно ничего настраивать не нужно: репозиторий лежит в корне хранилища.
3. При первом push Git попросит войти в GitHub (откроется браузер). Чтобы push прошёл, тебя должны добавить в Collaborators репозитория.

Основные команды (Ctrl+P):
- **Git: Pull** - забрать изменения;
- **Git: Commit-and-sync** - закоммитить свои правки, забрать чужие и отправить свои.

В настройках плагина можно включить автоматический commit-and-sync по таймеру.

**Чтобы не было конфликтов:** перед началом работы делай Pull и не правь один и тот же файл одновременно со мной. Если конфликт всё же случился, Git пометит место в файле маркерами `<<<<<<<` / `>>>>>>>`: оставь нужный вариант, удали маркеры и закоммить.

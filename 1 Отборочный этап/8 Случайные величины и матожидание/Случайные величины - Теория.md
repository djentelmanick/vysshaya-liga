# Случайные величины, матожидание, оценки - теория

## 1. Совместное распределение (таблица)
Для дискретных $X,Y$ задана таблица $P(X=x_i,Y=y_j)=p_{ij}$.
- **Маргинальное:** $P(Y=y_j)=\sum_i p_{ij}$ (сумма по строке/столбцу).
- **Условное:** $P(X=x_i\mid Y=y_j)=\dfrac{p_{ij}}{P(Y=y_j)}$.
- **Условное матожидание:** $E[X\mid Y=y_j]=\sum_i x_i\,P(X=x_i\mid Y=y_j)$.

> [!tip] Алгоритм для задач про доходности
> 1. Найди **строку/столбец**, соответствующий условию (будь внимателен, где в таблице какая акция!).
> 2. Нормируй: раздели вероятности на их сумму.
> 3. Посчитай взвешенное среднее.

**Формула полного матожидания:** $E[X]=E\big[E[X\mid Y]\big]=\sum_j P(Y=y_j)E[X\mid Y=y_j]$.

## 2. Матожидание и дисперсия
- $E[aX+bY+c]=aEX+bEY+c$ (всегда, независимость не нужна).
- $\operatorname{Var}X=E X^2-(EX)^2$, отсюда $EX^2=\operatorname{Var}X+(EX)^2$.
- $\operatorname{Var}(aX+b)=a^2\operatorname{Var}X$.
- $\operatorname{Var}(X\pm Y)=\operatorname{Var}X+\operatorname{Var}Y\pm2\operatorname{cov}(X,Y)$; при независимости ковариация 0.
- Независимы ⇒ $E[XY]=EX\cdot EY$.

## 3. Ковариация и корреляция
$$\operatorname{cov}(X,Y)=E[XY]-EX\,EY,\qquad\rho=\frac{\operatorname{cov}(X,Y)}{\sqrt{\operatorname{Var}X\operatorname{Var}Y}}\in[-1,1].$$
- Билинейность: $\operatorname{cov}(X+Y,X-Y)=\operatorname{Var}X-\operatorname{Var}Y$.
- $\rho(X,aX+b)=\operatorname{sign}(a)$.
- Независимы ⇒ некоррелированы (обратное в общем случае неверно; для совместно нормальных - верно).

## 4. Основные распределения
| Распределение | Значения | $E$ | $\operatorname{Var}$ |
|---|---|---|---|
| Бернулли $(p)$ | 0, 1 | $p$ | $p(1-p)$ |
| Биномиальное $(n,p)$ | $0..n$ | $np$ | $np(1-p)$ |
| Геометрическое (число неудач до успеха) | $0,1,2,\dots$ | $\frac{1-p}p$ | $\frac{1-p}{p^2}$ |
| Геометрическое (номер первого успеха) | $1,2,\dots$ | $\frac1p$ | $\frac{1-p}{p^2}$ |
| Пуассон $(\lambda)$ | $0,1,\dots$ | $\lambda$ | $\lambda$ |
| Равномерное $[a,b]$ | | $\frac{a+b}2$ | $\frac{(b-a)^2}{12}$ |
| Экспоненциальное $(\lambda)$ | $x\ge0$ | $\frac1\lambda$ | $\frac1{\lambda^2}$ |
| Нормальное $N(\mu,\sigma^2)$ | | $\mu$ | $\sigma^2$ |

## 5. Свойства статистических оценок
Оценка $\hat\theta_n$ параметра $\theta$:
- **Несмещённая:** $E\hat\theta_n=\theta$ при всех $\theta$.
- **Асимптотически несмещённая:** $E\hat\theta_n\to\theta$.
- **Состоятельная:** $\hat\theta_n\to\theta$ по вероятности. Достаточно: $E\hat\theta\to\theta$ и $\operatorname{Var}\hat\theta\to0$.
- **Эффективная:** минимальная дисперсия среди несмещённых.

**Ключевые факты:**
- ЗБЧ: $\bar X\to EX$ ⇒ $\bar X$ состоятельна и несмещённа для $EX$.
- Если $g$ непрерывна, то $g(\bar X)$ - состоятельная оценка $g(EX)$.
- **Но** $E[g(\bar X)]\ne g(E\bar X)$ для нелинейной $g$ (неравенство Йенсена: для выпуклой $g$ $Eg(X)\ge g(EX)$). Поэтому оценки вида $1/\bar X$, $1/(1+\bar X)$ - **смещённые, но состоятельные**.
- Выборочная дисперсия с $\frac1n$ смещена, с $\frac1{n-1}$ - несмещённая.
- Для $U[0,\theta]$: $2\bar X$ - несмещённая; $\max X_i$ - смещённая ($E=\frac{n}{n+1}\theta$), но состоятельная.

## 6. Метод моментов
Приравниваем теоретические моменты к выборочным и решаем относительно параметра. Пример: геометрическое на $\{0,1,\dots\}$: $EX=\frac{1-p}p=\bar X$ ⇒ $\hat p=\frac{1}{1+\bar X}$.

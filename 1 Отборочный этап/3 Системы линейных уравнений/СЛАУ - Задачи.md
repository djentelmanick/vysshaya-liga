## Задачи олимпиады

### 3.1 (2025, №3)
- [ ] решена

Find a solution $(a,b,c)$ for the following linear system. Choose correct value of $a+b+c$.
$$\begin{cases}a+2b+3c=5,\\a-2b+4c=-5,\\a+3b-3c=26.\end{cases}$$
Варианты: $4$; $12$; $6$; $9$; $7$.

### 3.2 (2024, №1)
- [ ] решена

Найдите решение $(x_1,x_2,x_3)$ и укажите сумму $x_1+x_2+x_3$:
$$\begin{cases}3x_1-x_2-2x_3=-1\\4x_1+3x_2-5x_3=-15\\-5x_1+2x_2+7x_3=16\end{cases}$$
Варианты: $0$; $5$; $-5$; $1$.

### 3.3 (2023, №6)
- [ ] решена

Решите систему и выберите правильное решение:
$$\begin{cases}3x_1+x_2+2x_3=1\\x_1+6x_2+8x_3=5\\9x_1+2x_2+4x_3=2\end{cases}$$
1. $x_1=\frac12,\ x_2=-\frac14,\ x_3=\frac14$
2. $x_1=0,\ x_2=\frac12,\ x_3=\frac14$
3. $x_1=\frac12,\ x_2=-\frac12,\ x_3=\frac14$
4. $x_1=0,\ x_2=-\frac12,\ x_3=\frac14$

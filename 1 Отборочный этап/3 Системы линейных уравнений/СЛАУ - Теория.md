# Системы линейных уравнений (СЛАУ) - теория

## 1. Запись
$$A\mathbf x=\mathbf b,\quad A\in\mathbb R^{m\times n}.$$
Расширенная матрица $(A\,|\,\mathbf b)$.

## 2. Когда есть решения: теорема Кронекера-Капелли
- $\operatorname{rank}A\ne\operatorname{rank}(A|b)$: решений нет.
- $\operatorname{rank}A=\operatorname{rank}(A|b)=n$: решение единственное.
- $\operatorname{rank}A=\operatorname{rank}(A|b)<n$: бесконечно много решений ($n-\operatorname{rank}$ свободных переменных).

Для квадратной системы: $\det A\ne0$ ⇔ решение единственное.

## 3. Метод Гаусса
1. Выбираем ведущее уравнение (удобно, когда коэффициент 1 или -1).
2. Вычитаем его с множителем из остальных, обнуляя первую переменную.
3. Повторяем для оставшейся подсистемы, затем обратный ход.

> [!tip] Удобнее всего вычитать уравнения, где коэффициент при одной переменной одинаковый (например, при $a$ везде 1).

## 4. Правило Крамера
$$x_i=\frac{\det A_i}{\det A},$$
где $A_i$ - матрица $A$ с $i$-м столбцом, заменённым на $\mathbf b$. Хорошо для систем 2×2, для 3×3 уже медленно.

Для 2×2: $\begin{cases}a_1x+b_1y=c_1\\a_2x+b_2y=c_2\end{cases}$, $\;x=\dfrac{c_1b_2-c_2b_1}{a_1b_2-a_2b_1}$, $y=\dfrac{a_1c_2-a_2c_1}{a_1b_2-a_2b_1}$.

## 5. Приёмы для тестов
- **Подстановка вариантов.** Если варианты - готовые решения, проверь их в уравнениях; часто хватает одного уравнения, чтобы отсечь половину.
- **Спрашивают $a+b+c$?** Попробуй подобрать линейную комбинацию уравнений, дающую $a+b+c$ напрямую (например, при симметричных коэффициентах сложить все уравнения).
- **Проверка ответа:** подставь найденное решение во все уравнения. Это 30 секунд, которые спасают от арифметической ошибки.
- **Параметр:** система с параметром $k$ вырождена при $\det A(k)=0$; дальше отдельно проверяем, есть ли решения (совместность).

## 6. Однородная система
$A\mathbf x=0$ всегда имеет $\mathbf x=0$. Нетривиальное решение есть ⇔ $\det A=0$ (для квадратной).

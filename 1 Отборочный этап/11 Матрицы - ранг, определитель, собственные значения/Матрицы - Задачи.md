# Матрицы - задачи

## Задачи олимпиады

### 11.1 (2023, №10)
Найти ранг матрицы
$A=\begin{pmatrix}-1&0&3&7\\0&-4&2&4\\9&1&1&3\\2&0&2&3\end{pmatrix}$.
Варианты: 3; 1; 4; 2.

### 11.2 (2022, №3)
Чему равна сумма всех (с учётом кратности) собственных значений матрицы
$A=\begin{pmatrix}-13&-3&18\\-20&-4&26\\-14&-3&19\end{pmatrix}$?
Варианты: 2; -4; 0; $\sqrt2$.

### 11.3 (2022, №4)
Найти ранг матрицы $A=\begin{pmatrix}1&2&5&6\\3&4&7&8\\0&0&9&10\\0&0&11&12\end{pmatrix}$.
Варианты: 4; 2; 3; 1.

### 11.4 (2021, №1)
Какое из чисел **не является** собственным значением матрицы
$\begin{pmatrix}3&0&-5\\1/5&-1&0\\1&1&-2\end{pmatrix}$?
Варианты: 2; нет верного ответа; 0; $\sqrt2$; $-\sqrt2$.

### 11.5 (2021, №2)
Вычислите $\det(A^{-1})$ для
$A=\begin{pmatrix}1&-1&5&1\\-2&1&-7&1\\-3&2&-12&-2\\2&-1&9&1\end{pmatrix}$.
Варианты: нет верного ответа; 4; $-1/4$; $-4$; $1/4$.

# Метрики ML - задачи

## Задачи олимпиады

### 6.1 (2025, №6)
Допустим, у вас есть бинарный классификатор с точностью (precision) 0,35 и F1-мерой 0,3. Каково значение полноты (recall)?
Варианты: $1/20$; $9/23$; $54/427$; $60/379$; $3/7$.

### 6.2 (2024, №7)
Бинарный классификатор с точностью (precision) 0,8 и F1-мерой 0,6. Каково значение полноты (recall)?
Варианты: 0,72; 0,4; 0,6; 0,48.

### 6.3 (2024, №8)
Какая функция потерь обычно используется в алгоритме градиентного бустинга для задачи бинарной классификации?
1. Кросс-энтропия (Log loss)
2. Среднеквадратичная ошибка (MSE)
3. Коэффициент Джини (Gini impurity)
4. Абсолютное отклонение

# Метрики качества и функции потерь в ML - теория

## 1. Матрица ошибок (бинарная классификация)
| | предсказано 1 | предсказано 0 |
|---|---|---|
| **на самом деле 1** | TP | FN |
| **на самом деле 0** | FP | TN |

## 2. Метрики
- **Accuracy (доля правильных):** $\dfrac{TP+TN}{TP+TN+FP+FN}$
- **Precision (точность):** $P=\dfrac{TP}{TP+FP}$ - какая доля предсказанных «1» верна.
- **Recall (полнота, TPR):** $R=\dfrac{TP}{TP+FN}$ - какую долю настоящих «1» нашли.
- **Specificity (TNR):** $\dfrac{TN}{TN+FP}$; **FPR** $=1-$ specificity.
- **F1-мера** - гармоническое среднее $P$ и $R$:
$$F_1=\frac{2PR}{P+R}\quad\Longleftrightarrow\quad\frac{2}{F_1}=\frac1P+\frac1R.$$
- **$F_\beta$:** $\dfrac{(1+\beta^2)PR}{\beta^2P+R}$ ($\beta>1$ - важнее полнота).

> [!important] Выразить одно через другое
> $$R=\frac{F_1\,P}{2P-F_1},\qquad P=\frac{F_1\,R}{2R-F_1}.$$
> Удобнее через обратные величины: $\frac1R=\frac2{F_1}-\frac1P$.

**Свойства F1:** лежит между $\min(P,R)$ и $\max(P,R)$, ближе к меньшему. При фиксированном $P$ максимум $F_1$ (при $R=1$) равен $\frac{2P}{1+P}$, поэтому некоторые сочетания невозможны.

**ROC-AUC** - площадь под кривой TPR(FPR); равна вероятности, что случайный положительный объект получит скор выше случайного отрицательного. 0,5 - случайное угадывание.

## 3. Функции потерь
| Задача | Функция потерь | Формула |
|---|---|---|
| Регрессия | MSE | $\frac1n\sum(y-\hat y)^2$ |
| Регрессия (устойчиво к выбросам) | MAE, Huber | $\frac1n\sum\lvert y-\hat y\rvert$ |
| Бинарная классификация | **Log loss (кросс-энтропия)** | $-\frac1n\sum\big[y\ln p+(1-y)\ln(1-p)\big]$ |
| Многоклассовая | Кросс-энтропия | $-\sum_k y_k\ln p_k$ |
| SVM | Hinge | $\max(0,\ 1-y\cdot f(x))$, $y\in\{-1,1\}$ |

- Минимум MSE даёт среднее, минимум MAE - медиану.
- Градиент log loss по логиту $z$ (где $p=\sigma(z)$): $p-y$.

## 4. Критерии разбиения в деревьях (это НЕ функции потерь бустинга)
- **Gini impurity:** $G=1-\sum_k p_k^2$ (для двух классов $2p(1-p)$).
- **Энтропия:** $H=-\sum_k p_k\log_2 p_k$.

Они используются при построении одного дерева для выбора разбиения.

## 5. Градиентный бустинг
- Ансамбль деревьев, каждое следующее обучается на **антиградиент функции потерь** (для MSE это просто остатки $y-\hat y$).
- Бинарная классификация: обычно **log loss** (выход модели - логит, через сигмоиду получается вероятность).
- Регрессия: MSE (или MAE/Huber).
- Ранжирование: специальные потери (pairwise, LambdaRank).

## 6. Прочее, что полезно знать
- **Переобучение:** низкая ошибка на train, высокая на test. Лечится регуляризацией (L1 - разреженность весов, L2 - малые веса), увеличением данных, ранней остановкой.
- **Bias-variance:** простая модель - высокое смещение, сложная - высокий разброс.
- **Кросс-валидация:** k-fold, оценка качества на отложенных частях.

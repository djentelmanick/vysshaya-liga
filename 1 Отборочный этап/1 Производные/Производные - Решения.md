# Производные - решения

### 1.1 (2025) - Ответ: **0,072**
$\sigma''=\sigma(1-\sigma)(1-2\sigma)$. Подставляем $\sigma=0.1$:
$$\sigma''=0.1\cdot0.9\cdot(1-0.2)=0.09\cdot0.8=0.072.$$
Искать $x=-\ln 9$ не нужно.

### 1.2 (2023) - Ответ: **$u_x=\frac{1}{1+x^2}$, $u_y=\frac{1}{1+y^2}$** (вариант 4)
По формуле сложения $\operatorname{arctg}\frac{x+y}{1-xy}=\operatorname{arctg}x+\operatorname{arctg}y+\pi k$ (константа на каждой области). Значит, $u_x=\frac{1}{1+x^2}$, $u_y=\frac{1}{1+y^2}$.

Быстрая проверка: при $y=0$ имеем $u=\operatorname{arctg}x$, значит $u_x=\frac{1}{1+x^2}$. Остаётся только вариант 4.

### 1.3 - Ответ: **−0,096**
$0.8\cdot0.2\cdot(1-1.6)=0.16\cdot(-0.6)=-0.096$.

### 1.4 - Ответ: **−0,125**
$\sigma(0)=\tfrac12$: $\sigma'''=\tfrac12\cdot\tfrac12\cdot(1-3+1.5)=\tfrac14\cdot(-0.5)=-0.125$.

### 1.5 - Ответ: **−0,75**
$\operatorname{th}''=-2\operatorname{th}(1-\operatorname{th}^2)=-2\cdot0.5\cdot0.75=-0.75$.

### 1.6 - Ответ: **$u_x=\frac25$, $u_y=\frac45$**
$u_x=\frac{2x}{x^2+y^2}=\frac{2}{5}$, $u_y=\frac{2y}{x^2+y^2}=\frac{4}{5}$.

### 1.7 - Ответ: **$u_x=-\frac{y}{x^2+y^2}$, $u_y=\frac{x}{x^2+y^2}$**
$u_x=\frac{1}{1+y^2/x^2}\cdot\left(-\frac{y}{x^2}\right)=-\frac{y}{x^2+y^2}$; $u_y=\frac{1}{1+y^2/x^2}\cdot\frac1x=\frac{x}{x^2+y^2}$.

### 1.8 - Ответ: **1**
$\ln f=x\ln x\Rightarrow f'=x^x(\ln x+1)$, $f'(1)=1\cdot(0+1)=1$.

### 1.9 - Ответ: **−0,9**
$\frac{\partial L}{\partial z}=p-y=0.1-1=-0.9$.
Вывод: $\frac{\partial L}{\partial p}=-\frac yp+\frac{1-y}{1-p}$, $\frac{dp}{dz}=p(1-p)$, произведение $=-y(1-p)+(1-y)p=p-y$.

# Алгоритмы - задачи

## Задачи олимпиады

### 12.1 (2024, №2)
Наивный способ вычисления $x^n$ - $x\times x\times\dots\times x$, это $n-1$ умножение. Есть более эффективные алгоритмы.

*Алгоритм 1:* если $n=1$, ответить $x$. Если $n>1$, рекурсивно вычислить $y:=x^{\lfloor n/2\rfloor}$ и ответить $y\times y$, если $n$ чётное, либо $y\times y\times x$ иначе.

*Алгоритм 2:* если $n=1$, ответить $x$. Если $n$ простое, рекурсивно вычислить $y:=x^{n-1}$ и ответить $x\times y$. Иначе рекурсивно вычислить $y:=x^p$, где $p$ - наименьший простой множитель $n$, затем рекурсивно вычислить $y^{n/p}$.

Алгоритм выигрывает у другого при данном $n$, если выполняет строго меньше умножений. Выберите все верные утверждения:
1. Для $n=15$ алгоритм 2 выигрывает у алгоритма 1.
2. Для $n=23$ можно выиграть у обоих алгоритмов.
3. Для $n=23$ алгоритм 2 выигрывает у алгоритма 1.
4. Алгоритм 1 никогда не выигрывает у алгоритма 2.

### 12.2 (2023, №5)
Какое утверждение **неверно**?
1. Для любого узла в двоичном дереве поиска оба поддерева - левое и правое - являются двоичными деревьями поиска.
2. Сложность сортировки подсчётом в худшем случае составляет $O(n\log n)$.
3. При помощи хеш-таблиц можно ускорить поиск элемента в произвольном массиве до $O(1)$.
4. Сложность быстрой сортировки в худшем случае составляет $O(n^2)$.

### 12.3 (2022, №7)
Какое утверждение **не является** верным?
1. Не существует алгоритма сортировки на сравнениях, работающего быстрее $O(n\log n)$ на произвольном массиве длины $n$.
2. Алгоритм сортировки на сравнениях можно сделать устойчивым с помощью модификации ключей.
3. Сортировка слиянием - это алгоритм сортировки, не основанный на сравнениях.
4. Сортировка подсчётом - это алгоритм сортировки, не основанный на сравнениях.

### 12.4 (2021, №7)
Массив $A[1:n]$ ($n>1000$) из различных чисел упорядочен по убыванию. Какой алгоритм быстрее (за меньшее число сравнений) отсортирует его по возрастанию?

### 12.5 (2021, №10)
Абитуриенты были отсортированы по ФИО. После экзамена список отсортировали по убыванию баллов одним из алгоритмов. Среди абитуриентов с одинаковыми баллами порядок ФИО оказался нарушен. Какая сортировка была использована?

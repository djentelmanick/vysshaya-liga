# Графы - задачи

## Задачи олимпиады

### 9.1 (2025, №9)
Какое минимальное количество рёбер в ненаправленном графе с количеством вершин 2025 может быть, чтобы он: 1) был связным; 2) было нельзя, удалив какие-либо две вершины, разбить его на две или более компоненты связности? Петли не учитываем.
Варианты: 2026; 2025; 2027; 2029; 2028.

### 9.2 (2023, №4)
Остовным деревом графа называется дерево, являющееся подграфом данного графа, вершинами которого являются все вершины графа. Какое из утверждений верно?
1. Остовное дерево можно найти за $O(n\log n)$ операций, где $n$ - число рёбер графа.
2. Остовное дерево графа не может быть найдено с помощью обходов в ширину.
3. Связный и ациклический подграф, обладающий минимальным суммарным весом рёбер и включающий все вершины, является минимальным остовным деревом.
4. Остовный лес является остовным деревом, если он ациклический и несвязный.

### 9.3 (2022, №8)
Какое из утверждений об остовном дереве **не является** верным?
1. Остовное дерево связного графа с $n$ вершинами содержит ровно $n-1$ ребро.
2. Остовное дерево может быть найдено с помощью обхода в ширину.
3. Остовное дерево можно найти за $O(\log n)$ операций, где $n$ - число вершин.
4. Остовное дерево может быть найдено с помощью обхода в глубину.

### 9.4 (2021, №8)
В связном дереве с $n$ вершинами производится обход в глубину из вершины $A$. Вершина $B$ соединена ребром с $A$ и не является листом. Оказалось, что $k$ вершин было помечено пройденными после того, как была помечена вершина $B$. Каким может быть наименьшее значение $k$?
Варианты: нет верного ответа; 1; $n-2$; 0; $n/2$.

### 9.5 (2021, №9)
Сколько дополнительной памяти требуется для обхода в глубину связного дерева с $m$ рёбрами, заданного списком смежности? Укажите наиболее точную асимптотику.
Варианты: $O(m\log m)$; $O(1)$; нет верного ответа; $O(m)$; $O(\log m)$.

### 9.6 (2021, №13)
Сколько существует (с точностью до изоморфизма) простых неориентированных графов на 8 вершинах, каждая из которых имеет степень 5?
Варианты: 0; 1; 2; 3; 4; нет верного ответа.

### 9.7 (2021, №14)
Простой неориентированный граф имеет 8 вершин, степень каждой равна 5. Выберите верный ответ:
1. обязательно есть гамильтонов цикл, и он может быть планарен
2. обязательно есть гамильтонов цикл, и он обязательно непланарен
3. может не быть гамильтонова цикла, и он обязательно планарен
4. может не быть гамильтонова цикла, и он обязательно непланарен
5. все ответы неверны

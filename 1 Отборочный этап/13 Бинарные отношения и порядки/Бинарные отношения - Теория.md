# Бинарные отношения и порядки - теория

## 1. Определение
Бинарное отношение $P$ на множестве $X$ - подмножество $X\times X$. Пишем $xPy$, если $(x,y)\in P$. Удобно рисовать как ориентированный граф или матрицу 0/1.

## 2. Свойства
| Свойство | Определение | В графе |
|---|---|---|
| Рефлексивность | $\forall x:\ xPx$ | петли у всех |
| Иррефлексивность | $\forall x:\ \lnot xPx$ | петель нет |
| Симметричность | $xPy\Rightarrow yPx$ | все стрелки двусторонние |
| Антисимметричность | $xPy\land yPx\Rightarrow x=y$ | нет двусторонних стрелок между разными |
| **Асимметричность** | $xPy\Rightarrow\lnot yPx$ | антисимметрично **и** иррефлексивно |
| Транзитивность | $xPy\land yPz\Rightarrow xPz$ | есть «короткий путь» вместо каждого пути длины 2 |
| **Полнота** | $\forall x,y:\ xPy\lor yPx$ (в т.ч. $x=y$) | любые два сравнимы, петли есть |
| **Связность** (слабая полнота) | $\forall x\ne y:\ xPy\lor yPx$ | любые два различных сравнимы |

> [!warning] Ловушка
> Асимметричность ≠ антисимметричность. Рефлексивное отношение **никогда** не асимметрично (из $xPx$ следовало бы $\lnot xPx$).

## 3. Типы отношений
- **Эквивалентность:** рефлексивно + симметрично + транзитивно. Разбивает множество на классы.
- **Нестрогий частичный порядок ($\preceq$):** рефлексивно + антисимметрично + транзитивно. Пример: делимость на $\mathbb N$, $\subseteq$.
- **Строгий частичный порядок ($\prec$):** иррефлексивно (⇒ асимметрично) + транзитивно.
- **Линейный (полный) порядок:** частичный порядок, где любые два элемента сравнимы.
- **Предпорядок:** рефлексивно + транзитивно.

## 4. Подсчёты на множестве из $n$ элементов
- Всех отношений: $2^{n^2}$; рефлексивных: $2^{n^2-n}$; симметричных: $2^{n(n+1)/2}$.
- Линейных порядков: $n!$.
- Пар в **строгом** линейном порядке: $C_n^2=\frac{n(n-1)}2$; в **нестрогом**: $\frac{n(n-1)}2+n=\frac{n(n+1)}2$.
- Линейных порядков, согласованных с заданными цепочками (непересекающимися) длин $k_1,k_2,\dots$: $\dfrac{n!}{k_1!\,k_2!\cdots}$ - внутри каждой цепочки из $k_i!$ взаимных порядков подходит ровно один.

## 5. Как проверять свойства конкретного отношения
1. Выпиши все пары (на маленьком множестве это быстро).
2. Рефлексивность - есть ли все $(x,x)$.
3. Симметричность - найди хоть одну пару без обратной.
4. Транзитивность - проверь «цепочки» $x\to y\to z$; для отношений через делимость/умножение проверяй алгебраически (произведение нечётных нечётно и т.п.).
5. Полнота/связность - найди пару несравнимых.

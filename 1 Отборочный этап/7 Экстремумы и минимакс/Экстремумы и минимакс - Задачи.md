# Экстремумы и минимакс - задачи

## Задачи олимпиады

### 7.1 (2025, №7)
Let $f=(x-a)^2-a$ and $x,y\in[-1,1]$. Find $g=\left(\min_a\max_x f-\max_a\max_x f\right)$.
Варианты: $2$; $0{,}25$; $4$; $0$; $2{,}5$.
*(В условии, видимо, опечатка: вместо $y$ имеется в виду $a$, то есть $x,a\in[-1,1]$.)*

### 7.2 (2024, №4)
Рассмотрим функцию $f(x)=3x^3(x-2)^2$. Выберите верный ответ:
1. При $x=0$ функция имеет локальный минимум
2. При $x=2$ функция имеет локальный максимум
3. При $x=2$ функция имеет локальный минимум
4. При $x=-2$ функция имеет локальный максимум

### 7.3 (2023, №8)
Рассмотрим функцию $y=\left(\frac{1+x}{1-x}\right)^4$. Выберите верное утверждение:
1. Минимум $y=0$ при $x=-1$; точки перегиба отсутствуют; асимптоты $x=0$, $y=1$.
2. Минимум $y=0$ при $x=-1$; точка перегиба $x=-4$, $y=\frac{81}{625}$; асимптоты $x=1$, $y=1$.
3. Минимум $y=0$ при $x=1$; точка перегиба $x=-4$, $y=\frac{81}{625}$; асимптоты $x=0$, $y=1$.
4. Минимум $y=0$ при $x=1$; точки перегиба отсутствуют; асимптоты $x=1$, $y=1$.

### 7.4 (2022, №1)
Рассмотрим функцию $f(x)=1-x^2+x^3$. Выберите все верные утверждения:
1. При $x=0$ функция имеет локальный максимум
2. При $x=0$ функция имеет точку перегиба
3. При $x=0$ функция имеет локальный минимум
4. При $x=0$ функция имеет локальный экстремум

### 7.5 (2021, №6)
Функция $F(x,y)=x^2-2xy+2y^2+x+1$:
имеет глобальный максимум / не имеет стационарных точек / имеет глобальный минимум / нет верного ответа / имеет седловую точку.
